# Web サービス・SaaS の M&A アドバイザリー

## 個人開発サービスの買取・仲介

弊社で買取します。または売り手への譲渡・売却を仲介・支援します。

### 手続きの流れ

1. **初回ヒアリング**

   - サービス概要の確認
   - 売却希望理由の確認
   - 希望条件（価格、条件など）の確認

2. **事業・コード評価**

   - 技術的な評価（コード品質、アーキテクチャ、依存関係）
   - 事業的な評価（収益性、顧客基盤、成長性）
   - 適正価格の算定

3. **買取・仲介の決定**

   - 弊社での買取可否の判断
   - または適切な買い手への仲介

4. **契約・クロージング**

   - 契約条件の調整
   - デューデリジェンスの実施
   - クロージング手続き

5. **移行支援**
   - 技術移行のサポート
   - データ移行の支援
   - 引き継ぎ業務の支援

## 買い手支援

SaaS やサービスの査定・調達・購買支援を行います。

### 手続きの流れ

1. **購入希望のヒアリング**

   - 購入希望のサービス・事業の要件確認
   - 予算・条件の確認
   - 購入目的の明確化

2. **候補サービスの探索・評価**

   - 市場調査・候補サービスの探索
   - 技術デューデリジェンスの実施
     - コード品質の評価
     - 依存関係の確認
     - 保守リスクの評価
     - 移行可否の判断
   - 事業デューデリジェンスの実施
     - 財務状況の確認
     - 顧客基盤の評価
     - 成長性の評価

3. **交渉・契約支援**

   - 適正価格の算定
   - 契約条件の調整
   - 交渉のサポート

4. **クロージング**

   - 最終的な契約条件の確定
   - クロージング手続きの支援

5. **移行・統合支援**
   - 技術移行の計画・実行支援
   - データ移行の支援
   - チーム統合のサポート

## 売り手支援

個人開発サービスや小規模 SaaS の売却を支援します。

### 手続きの流れ

1. **売却希望のヒアリング**

   - サービス概要の確認
   - 売却理由の確認
   - 希望条件（価格、条件など）の確認

2. **事業・コード評価**

   - 技術的な評価
     - コード品質の評価
     - アーキテクチャの評価
     - 依存関係の確認
     - 保守リスクの評価
   - 事業的な評価
     - 収益性の分析
     - 顧客基盤の評価
     - 成長性の評価
   - 適正価格の算定

3. **譲渡準備**

   - ティーザーの作成
   - 情報開示資料（IM）の作成
   - 移行チェックリストの作成
   - デューデリジェンス準備

4. **買い手の探索・マッチング**

   - 適切な買い手の探索
   - 買い手への提案
   - マッチングの調整

5. **交渉・契約支援**

   - 交渉のサポート
   - 契約条件の調整
   - 法的アドバイスの提供

6. **クロージング**

   - 最終的な契約条件の確定
   - クロージング手続きの支援

7. **移行支援**
   - 技術移行のサポート
   - データ移行の支援
   - 引き継ぎ業務の支援

## 成果物例

- **ティーザー**: サービス概要を簡潔にまとめた資料
- **IM（Information Memorandum）**: 詳細な情報開示資料
- **移行チェックリスト**: 技術移行に必要な項目をまとめたチェックリスト
- **技術デューデリジェンスレポート**: コード品質、依存関係、保守リスクなどの評価レポート
